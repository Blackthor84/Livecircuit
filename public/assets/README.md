# Public Artist Bible Assets

Served at `/assets/*`. Mirror of `src/assets/` structure.

Place final artwork here:

- `artists/{id}/` — performer PNGs
- `logos/` — brand logos
- `albums/` — album covers
- `tours/` — tour posters
- `merch/{id}/` — merchandise
- `backgrounds/` — arena banners

Fallback stage poses: `/demo/performers/` (shared genre pool).
